The examples use the public node at `https://haatz.quilibrium.com`. Your own node answers the same paths on `http://localhost:3381`. Set `NODE` once and the commands work against either:

```sh
NODE=https://haatz.quilibrium.com
```

For the full protocol, see [docs.farcaster.xyz](https://docs.farcaster.xyz) and [snapchain.farcaster.xyz](https://snapchain.farcaster.xyz).
